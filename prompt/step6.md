#### 4. 移动端体验检查

请确认：

- 375px 宽度下布局正常

#### 5. 工程化检查

请确认：

- views 只负责页面组装
- components 职责明确
- stores 不直接承担复杂 UI 逻辑
- repositories 只负责持久化
- utils 是纯函数
- 统计逻辑没有散落在模板里
- 没有重复常量
- 没有硬编码旧日期
- 注释清楚但不过量

如果发现以下问题，请主动重构：

- 单个组件超过 250 行且职责混杂
- 重复逻辑超过 2 次
- localStorage 访问出现在 repository 以外
- 日期处理散落在多个文件
- 统计逻辑写在组件里
- 类型定义重复
- 组件命名不统一
